## 2. ปัญหาที่โครงใหม่ต้องแก้ (จากออดิท)

- บอร์ดมี **30 ลิสต์** (25 เปิด + 5 ถูก archive) ปนกัน 3 แกน → การ์ดไม่รู้จะอยู่ไหน
- **462 การ์ดแดชบอร์ดมองไม่เห็น** (แก้แล้ว 12 ส.ค.) — `LIST_MAP` รู้จัก 10 ชื่อลิสต์ + fallback ชื่อเดือนไทยครอบอีก 303 ใบ ที่เหลือถูกข้ามทิ้ง

  ⚠️ ตัวเลข "765 ใบ / 58%" ที่รายงานไว้เดิมสูงเกินจริง — ไม่ได้นับ fallback ชื่อเดือนที่มีอยู่แล้วในโค้ด

- ค้าง 227 ใบใน "ผ่านการรีวิว" + 63 ใบใน "แก้ไข" เพราะไม่มีสเตจที่บังคับให้ใส่วันโพสต์

## 3. โครงลิสต์ใหม่ — 7 สเตจ + 2 ลิสต์ประกอบ

```
[1] ไอเดีย → [2] วางแผน → [3] ผลิต → [4] ตรวจ → [5] แก้ไข ⟲
                                          ↓
                                    [6] รอโพสต์ → [7] โพสต์แล้ว
```

| # | ลิสต์ใหม่ | ความหมาย | เงื่อนไขเข้า |
|---|---|---|---|
| 1 | **ไอเดีย** | ยังไม่ผูกเดือน | มีชื่อเรื่อง |
| 2 | **วางแผน (M+2)** | ผูกเดือนเป้าหมายแล้ว | มีเจ้าของ + เดือนเป้าหมาย |
| 3 | **ผลิต** | ถ่าย/ตัด/ออกแบบอยู่ | มีกำหนดส่ง (due) |
| 4 | **ตรวจ** | ตองตรวจ → เซินรีวิว | มีไฟล์งานแนบในการ์ด |
| 5 | **แก้ไข** | ตีกลับ | ต้องมีคอมเมนต์บอกว่าให้แก้อะไร |
| 6 | **รอโพสต์** | ผ่านแล้ว รอถึงวัน | **ต้องมีวันโพสต์ (due) เสมอ** |
| 7 | **โพสต์แล้ว** | จบงาน | **ต้องมีลิงก์โพสต์ + thumbnail** |
| — | **งานประจำเดือน** | routine ที่ทำซ้ำทุกเดือน | นอกสายการผลิต |
| — | **คลัง (archive)** | ของเก่า/ไม่ใช้แล้ว | — |

**หายไปจากบอร์ด:** ลิสต์รายเดือนทุกอัน (กุมภาพันธ์–สิงหาคม 2569), ลิสต์สรุปย้อนหลัง 6 อัน, ลิสต์ Ads/โปรแยกเดือน 5 อัน, to do list today, ดำเนินการเรียบร้อย ✅, Card Template
**เหตุผล:** "เดือน" ไม่ใช่สเตจ — ใช้ **วันครบกำหนด (due)** แทน แล้วกรองด้วยปฏิทิน Trello หรือแดชบอร์ดได้ทันที ส่วนประวัติย้อนหลังอยู่ใน hub ครบแล้ว (ดูดรายวันตั้งแต่ต้นปี)

### ป้าย (label) 3 ชุด แทนลิสต์ที่ยุบ
| ชุด | ค่า | แทนลิสต์เดิม |
|---|---|---|
| **คน** | ตอง · แฟร์ · ปาย · แป้ง (+ แยม/ครีม ถ้ายังมีงานค้าง) | — (มีอยู่แล้ว แต่ต้องล้าง `เเป้ง`/`ใบตอง` ซ้ำ) |
| **ประเภท** | คลิปสั้น · คลิปยาว · รูป · Ads · HomeProgram · โปรโมชั่น | Ads*, HomeProgram, โปรเดือน* |
| **แผนก** | กายภาพ · กระดูกและข้อ · พิลาทิส · Hybrid · นวด | — (ใหม่) |

หมายเหตุ label คนตอนนี้ซ้ำซ้อน: `ใบตอง` มี 2 ป้ายคนละสี (75 + 53) และ `เเป้ง` สะกดผิด (16) — `content_trello` มี `WHO_MAP` แก้ให้เฉพาะ `เเป้ง` เท่านั้น ต้องล้างที่ต้นทาง

**ต้องเคาะ:** เกณฑ์ ">90 วัน = เข้าคลัง" ใช้ได้ไหมคะ หรืออยากให้ตองไล่ดูทีละใบก่อน (156 ใบ) — ผมแนะนำให้ตองไล่เฉพาะช่วง 31–90 วัน (91 ใบ) เพราะเป็นของที่ยังพอใช้ได้ ส่วน >90 วัน โปรโมชั่น/เทรนด์หมดอายุไปแล้วเป็นส่วนใหญ่

**เข้าคลัง = archive การ์ด ไม่ใช่ลบ** กู้กลับได้ตลอด และข้อมูลทุกใบมีสำเนาใน hub อยู่แล้ว

## 8. เรื่องความปลอดภัยที่ค้างอยู่ (แยกจากงาน Trello)

การออก token ใหม่ของ LINE OA และเพจ Facebook **ต้องทำจากคอนโซลด้วยบัญชีพี่เซินเอง** (ผมเข้าระบบที่ต้องใส่รหัสผ่านแทนไม่ได้) — ขั้นตอน:
1. LINE Developers Console → channel ของ OA → ออก Channel Access Token ใหม่ → revoke ตัวเก่า
2. Meta Business → System User → ออก token ใหม่ให้ครบทุกเพจ → ถอนตัวเก่า
3. ส่งค่าใหม่ให้ผมทาง **ช่องทางที่ไม่ใช่แชตกลุ่ม** แล้วผมใส่เข้า Script Properties / Supabase secrets ให้ (ไม่กลับเข้าชีตอีก)
4. ผมลบค่าเดิมออกจากแท็บ CONFIG + แก้โค้ดให้อ่านจาก secrets

ระหว่างสลับ token ระบบที่ใช้อยู่ (บอทน้องใบ, ตัวดึงยอดแอด) จะดับชั่วคราวไม่กี่นาที
